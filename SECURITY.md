# Security and sensitive data

This application is intended for localhost research evaluation. Authentication,
multi-user isolation and hosted deployment are outside its validated scope.

Never post credentials, private genomic data or suspected restricted records in a
public issue. Use GitHub private vulnerability reporting if enabled on the approved
repository. Otherwise request a private contact channel without attaching sensitive
content. No contact email is published here.

Default CI uses synthetic inputs and read-only repository permissions. No credential
or paid service is needed for the demo. Hash locks pin dependency distributions;
those distributions retain their own code and licensing conditions.
