# Contributing
Use Python 3.13 and scripts/setup.ps1. Run scripts/verify.py --software-only before a
source-only change. Run full Pytest and authorized research reconstruction when changing
scientific contracts, metrics, identity or statistical assumptions. Record selection,
skips/deselection, input versions, denominators and expected behavior.

Keep adapters separate from metrics. Test missing outcomes, ties, undefined statistics
and incompatible cohorts. Preserve failed findings and source/input/output hashes.
Use original synthetic fixtures. Do not submit credentials, private genomic records,
restricted data, sequence-level outputs or unsupported scientific claims.

Retain MIT and third-party attribution. See SECURITY.md for sensitive-file concerns.
Maintainers must review publication and visibility changes.
